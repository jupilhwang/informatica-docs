# P11. AI & CLAIRE
> CLAIRE GPT, CLAIRE Copilot, 데이터 관리 에이전트를 써서 자산 탐색, 품질 진단, ELT 파이프라인 생성을 자연어 프롬프트로 처리한다.

## 이 단계에서 배우는 것
- CLAIRE GPT 대화 인터페이스 사용법: 샘플 프롬프트(#), 자산 참조(@), 대화 메모리 초기화
- CLAIRE GPT를 제대로 쓰기 위한 최소 준비: catalog source, Data Gateway Service, Data Integration 서비스
- CLAIRE Copilot으로 서비스 안에서 mapping, ingestion 작업, process를 만들고 요약하는 방법
- Discovery, Data Quality, Data Integration 에이전트별 skill과 제약
- 여러 에이전트를 이어 써서 복합 목표(예: 환자 데이터 분석과 정정)를 처리하는 흐름

## 실습 흐름 (LAB)
1. 사전 준비 사항(Before you begin)을 확인하고 CLAIRE GPT에 로그인한다. Home page의 샘플 프롬프트 카테고리를 살펴본다. [Introduction And Getting Started With CLAIRE GPT]
2. 프롬프트 창에 직접 입력하거나 #으로 샘플 프롬프트를 불러와 수정한 뒤 Submit으로 대화를 시작한다. [Introduction And Getting Started With CLAIRE GPT]
3. 먼저 IDMC 사용법을 질문한다(예: "How do I bulk import a glossary into the catalog?"). 답변은 How-To Library, Documentation portal, Knowledge Base를 종합해서 나온다. [Start your generative ai journey for data management with c]
4. Metadata Command Center에서 데이터 웨어하우스용 catalog source를 만들고 메타데이터를 추출한다. 이후 "Show data sets that have customer data"처럼 데이터 세트를 찾는다. [Start your generative ai journey for data management with c]
5. Secure Agent 하나 이상에서 IDMC Data Gateway Service가 돌고 있는지 확인한다. 그다음 "Show a preview of @SALESAMOUNT"로 원천 데이터를 미리 본다. [Start your generative ai journey for data management with c]
6. 런타임 환경에 Data Integration 서비스를 켠 뒤 "Create a mapping to load all customer data added in the last 6 months"로 ELT mapping을 만든다. [Start your generative ai journey for data management with c]
7. catalog source에서 Data Profiling과 Data Quality를 켜고 lineage용 connection을 지정한다. 이어서 "Show the data quality score of @CUSTOMERID", "Show the lineage of @CUSTOMERID"를 시도한다. 응답을 평가하고, 끝나면 대화 메모리를 지운다. ## 현업 팁 · 주의점
- CLAIRE GPT의 탐색 품질은 카탈로그 상태에 달려 있다. catalog source 추출, glossary 연결, Data Classification·Profiling·Data Quality capability를 먼저 켜 둔다.
- Data integration agent는 기존 데이터를 생성·이동·저장·삭제하지 못하고 기존 mapping도 편집하지 못한다. 실행하려면 Designer 역할이 있어야 한다.
- 데이터 탐색 프롬프트가 복잡한 SQL을 쓰면 Data Integration이 그 쿼리를 mapping으로 바꾸지 못할 수 있다.
- 개인정보 보호 지침에 따라 샘플 데이터는 저장되지 않는다. 브라우저를 새로고침하거나 로그아웃하면 사라지므로 필요하면 그 전에 CSV로 받아 둔다.
- 보안 관련 질문은 "Is CLAIRE GPT secure?" 프롬프트로 확인할 수 있다. 이전 프롬프트는 위·아래 화살표 키로 다시 불러온다.
